# Gold-Flap
Game for daydream organizer.

its basically flappy bird but with coins. you play as this little round guy and coins keep falling out of the sky, so you flap with space (or w, the up arrow, or clicking) and move left and right with the arrow keys to eat as many as you can. theres no floor, so if you touch the grass, the top of the screen, or either wall its game over. the coins fall faster the more you eat so it gets kinda hard after a while lol. made in godot
