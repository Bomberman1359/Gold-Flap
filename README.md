# Gold-Flap
Game for daydream organizer.

It's basically Flappy Bird but with coins. You play as this little round sprite and coins keep falling out of the sky, so you flap with Space (or W, the up arrow, or clicking) and move left and right with the arrow keys to eat as many as you can. There is no floor, so if you touch the grass, the top of the screen, or either wall, it's game over. The coins fall faster the more you eat, so it gets more difficult after a while. Made in Godot.
